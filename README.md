# Beyond-Administrative-Boundaries-Measuring-Ethnic-Disparities-in-Violent-Crime-Exposure-in-London

This repository contains the code accompanying the paper Beyond Administrative Boundaries: Measuring Ethnic Disparities in Violent Crime Exposure in London.

About this demo：To keep the example small and quick to run, this repository uses one London borough (Camden) and one year of crime data (2024). The paper covers all LSOAs in Greater London and uses crime data for 2022-2024. 
The workflow is the same， only the study area and time period differ.
